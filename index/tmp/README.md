# Index Temporary Files

This directory contains temporary/cache files generated during the index building process.

## Files

- **discovered_routes.json** - Cached documentation routes discovered from the Directus API
  - Auto-generated by `api_route_finder.py`
  - Contains URLs and metadata for all documentation pages
  - Used to speed up index building by avoiding repeated API calls

- **index_build.log** - Build logs from the index creation process
  - Generated by `index_builder.py`
  - Contains detailed information about crawling and indexing progress

## Note

This directory is excluded from git via `.gitignore`. The files here are regenerated as needed and should not be committed to version control.
